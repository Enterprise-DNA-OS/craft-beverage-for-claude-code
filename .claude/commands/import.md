# Bring across supported Vinsight exports

Run `npm run beverage -- import vinsight <folder> --dry-run`. Replace placeholders with the operator's values, quote values containing spaces, and use `--json` when composing another report.

Read docs/replace-vinsight.md first. Confirm headers, classification and litre units. Run the dry run, compare row counts, then repeat without --dry-run when the operator requests the import. Never promise orders or production history that the importer does not handle.

Present the records, their dates and any missing evidence. Ambiguous names must be resolved from the listed candidates. Never send, file a return or contact anyone. Drafts remain in `drafts/`.
