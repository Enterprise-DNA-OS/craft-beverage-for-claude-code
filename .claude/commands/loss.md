# Record a stock loss

Run `npm run beverage -- loss <batch> <location> <units> --ref=<unique-reference> --evidence=<reason-and-document>`. Replace placeholders with the operator's values, quote values containing spaces, and use `--json` when composing another report.

 Read the batch or order first. Use only operator-supplied evidence. Dispatch records a real physical event and never books a carrier or sends a message.

Present the records, their dates and any missing evidence. Ambiguous names must be resolved from the listed candidates. Never send, file a return or contact anyone. Drafts remain in `drafts/`.
