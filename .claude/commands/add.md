# Create a product, batch or order

Run `npm run beverage -- help`. Replace placeholders with the operator's values, quote values containing spaces, and use `--json` when composing another report.

Use the exact syntax in README.md. Ask for missing quantities, dates, codes and sources. Never invent a licence, ABV, tax classification or production reference.

Present the records, their dates and any missing evidence. Ambiguous names must be resolved from the listed candidates. Never send, file a return or contact anyone. Drafts remain in `drafts/`.
