# Weekly review

Run `dispatch-board`, `cellar-round` and `compliance` with `npm run beverage -- <command> --json`. Then run `stock-age` and `shortages` for context. Write the review to `drafts/weekly-review-YYYY-MM-DD.md`: overdue dispatches, shortages, held batches, missing records, then an owner and next step for each item where recorded. Never invent owners. Nothing sends.
